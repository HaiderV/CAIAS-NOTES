# 📚 CAIAS Notes

A modern, student-focused notes sharing platform built for the CAIAS community.

CAIAS Notes provides a centralized place where students can access, preview, download, and manage academic notes efficiently. The platform focuses on simplicity, accessibility, and a clean user experience across desktop and mobile devices.

---

## ✨ Features

### 🔐 Secure Authentication

- Google Sign-In using Firebase Authentication
- Restricted access to authorized CAIAS student accounts
- Protected routes for authenticated users

### 📖 Notes Management

- Upload notes in PDF format
- Download notes for offline access
- Organized note storage and retrieval

### 🗂️ Categories & Organization

- Structured note management
- Easy navigation and filtering
- Clean and intuitive interface

### 📢 Notice Board

- Dedicated communication channel for platform updates
- Announcements and important information
- Feature release notes
- Maintenance notifications

### 🐛 Bug Reporting & Support

- Built-in support section
- Users can report bugs and issues
- Feedback collection to improve the platform

### 🎨 Modern UI

- Responsive design for desktop, tablet, and mobile
- Light/Dark mode support
- Clean and accessible interface
- Optimized user experience

### ☁️ Cloud Storage

- Secure file storage
- Efficient note delivery
- Cloud-based asset management

## 🎯 Project Goals

- Make academic resources easily accessible.
- Reduce dependency on scattered note-sharing methods.
- Provide a centralized platform for students.
- Improve communication between students and administrators.
- Deliver a fast, modern, and reliable experience.

---

## 🔒 Access Policy

Access to the platform is limited to authorized CAIAS student accounts.

Authentication and authorization rules are enforced using Firebase Authentication and Firestore Security Rules.
